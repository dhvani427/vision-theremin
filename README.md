# Computer Vision Theremin Project

## Setup
```bash
npm install
npm run dev
```

Then open the printed local URL (e.g. `http://localhost:5173`) and click "Start Camera". The first run will download the MediaPipe hand-tracking model over the network, so expect a short delay before tracking starts.
